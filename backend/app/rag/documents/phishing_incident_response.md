
# Phishing Incident Response

## 1. If a suspicious link was clicked but no information was entered

Clicking a suspicious link does not automatically mean that a device or account has been compromised.

Recommended actions:

- Close the suspicious webpage.
- Do not enter passwords, financial information, or personal details.
- Do not download or execute files from the suspicious website.
- Do not grant unexpected browser permissions.
- Update the operating system and browser.
- Run a security scan if a file was downloaded, suspicious behavior occurs, or malware is suspected.
- Report the suspicious message to the relevant organization or security team.

## 2. If login credentials were entered

Treat the exposed credentials as compromised.

Recommended actions:

- Access the legitimate service using its official website or application.
- Change the affected password from a separate, trusted device.
- Change the password on other accounts where the same password was reused.
- Enable multi-factor authentication.
- Review recent account activity and unfamiliar login sessions.
- Sign out unfamiliar or untrusted sessions where the service allows it.
- Contact the service provider if unauthorized account activity is detected.

## 3. If financial or personal information was entered

Take action based on the information exposed.

- Contact the bank or financial institution immediately if banking or payment details were exposed.
- Ask the institution to secure affected accounts or payment instruments.
- Monitor transactions for unauthorized activity.
- Follow the relevant identity-protection and fraud-reporting procedures if personal identity information was exposed.

## 4. If a suspicious file was downloaded or executed

A downloaded file and an executed file represent different levels of risk.

Recommended actions:

- Do not open or execute the downloaded file.
- If suspicious software was executed or malware is suspected, disconnect the affected device from the network.
- Do not use the potentially compromised device to access sensitive accounts.
- Run an updated security scan using trusted security software.
- Install operating system and application security updates.
- Seek assistance from the organization's IT or security team if the device is managed by an employer.
- Change potentially exposed passwords using a separate, trusted device.

## 5. Reporting and prevention

- Report phishing emails through the email provider's reporting feature.
- Report suspicious messages to the relevant organization.
- Preserve relevant evidence when reporting an incident.
- Use unique passwords for different accounts.
- Enable multi-factor authentication.
- Keep operating systems, browsers, and security software updated.

## Downloaded a Suspicious File but Have Not Opened It

If a suspicious file was downloaded but has not been opened or executed:

1. Do not open, run, install, preview, or enable macros in the file.
2. Do not rename the file to make it appear safe.
3. Use reputable, up-to-date endpoint security software to scan the file.
4. Quarantine or delete the file using the security software. If the file is on a work device, contact the organization's IT or security team before deleting it.
5. Do not upload the file to public malware-scanning services if it may contain confidential, personal, or organizational information.
6. If the file was already opened or executed, treat the device as potentially compromised and follow the incident-response steps for executed suspicious files.

A website's appearance, domain name, HTTPS connection, or reputation does not establish that a downloaded file is safe.
